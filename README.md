## ✨ Key Features

- **Navigation Bar:** Responsive navbar with brand logo, links, and action button.
- **Hero Section:** Eye-catching full-width hero banner with bold heading and background imagery.
- **Speakers Showcase:** Organized speaker card grid displaying key conference speakers.
- **Pricing Section:** Clear tier plans with a visually highlighted featured pricing card.
- **Call-to-Action & Footer:** Engaging CTA section alongside a structured, responsive footer.
